**파일 위치**: `ai-agent/claude/261125_기말과제/261125_서버전환계획서.md`

**설명**: 기말 과제 공지(01~04, docker-check.yml)에 맞춰 Flask + SQLite 서버 앱을 새로 만드는 결정과 1주차 작업 범위를 정의한다.

## 1. 결정 기록

### ADR-019 서버 앱 전환 (Flask + Jinja2 + SQLite)

- **배경**: 과제 공지는 학교 서버에서 Docker 로 실행되는 웹 앱, SQLite DB, `0.0.0.0:8080` 응답, 점검 워크플로 통과를 요구한다. 기존 `web/` 은 서버가 없는 PWA(IndexedDB)라 점검 1단계(빌드)부터 통과할 수 없다.
- **대안**: Express + EJS (Node 유지, TS 도메인 규칙 재사용), FastAPI + Jinja2, React SPA 유지 + 백엔드 (공지가 권하지 않음).
- **결정 근거**: 공지가 권하는 "서버 템플릿 + 바닐라 JS" 방향이고, 공지 예시(python:3.13-slim, gunicorn, `utf-8-sig`)가 Python 기준이라 규칙 R-01~R-16 을 맞추기 가장 쉽다. `sqlite3` 가 표준 라이브러리라 의존성이 Flask, gunicorn 둘뿐이다. 사용자 승인 (261125).

### ADR-020 기존 web/ 유지, 서버는 server/ 에

- **배경**: 기존 PWA 와 Pages 배포를 지울지 정해야 했다.
- **대안**: `web/` 제거 또는 보관 태그만 남기기.
- **결정 근거**: 기존 작업을 보존한다. 루트 `Dockerfile` 은 `server/` 만 이미지에 넣고 `.dockerignore` 로 나머지를 뺀다. Pages 배포는 `web/**` 변경에만 돌아 점검 워크플로와 겹치지 않는다. 사용자 승인 (261125).

### ADR-021 제출용 문서 이름은 익스포트로 맞춤

- **배경**: 과제는 `docs/` 문서명을 `분류_yymmdd_제목 vX.X.md` 로 요구하지만, 프로젝트 규칙은 `YYMMDD_한글이름.md` 이다.
- **대안**: CLAUDE.md·방법론의 이름 규칙을 과제 규칙으로 바꾼다.
- **결정 근거**: 기존 마크다운은 고치지 않는다 (사용자 지시 261125). 제출 시점에만 `ai-agent/scripts/export_submission_docs.py` 로 이름만 바꿔 `docs/` 에 복사한다.

## 3. 서버 앱 구성 (1주차)

| 파일 | 내용 |
|---|---|
| `server/app.py` | `create_app()` 팩토리. `SECRET_KEY` 환경변수(없으면 `secrets.token_hex`), `DB_PATH` 로 DB 준비, `/` 라우트 |
| `server/db.py` | `resolve_db_path()`, `connect()` (commit/rollback 후 항상 닫음), `init_db()` (`CREATE TABLE IF NOT EXISTS`) |
| `server/templates/index.html` | 첫 화면. 등록 단어 수를 DB 에서 읽어 표시 |
| `server/tests/test_app.py` | 첫 화면 200, 테이블 자동 생성, 주소 규칙(R-04), 정적 파일 |

뼈대 테이블: `words`, `study_records`, `exam_answers`. 2주차에 데이터 설계서를 VOCA-FR 기준으로 다시 쓰면서 확정한다.

## 5. 주의 사항

- `docs/개발방법론.md` 는 프로젝트에 맞게 고친 사본이다. SUB-011 은 "수업 배포본 사본"을 요구하므로 원본 사본을 따로 둘지 확인이 필요하다.
- 커밋 작성자 이메일이 GitHub noreply 주소라 SUB-041(개인 구글 계정) 확인이 이메일로는 되지 않는다. 제출 폼 자가 신고로 대신한다.
- 제출한 뒤에는 force-push 하지 않는다 (공지 §6).
