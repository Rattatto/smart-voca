## 2. 기기 검증

- 설치 중 발견한 문제: 기능어 파일이 APK 에 들어가지 않아 앱이 시작하자마자 죽음 (`FileNotFoundException: function_words.csv`).
  - 원인: Gradle 에 루트 `src/main/assets` 를 등록하지 않음. 단위 테스트는 이를 잡지 못했음.
  - 조치: assets 경로 등록, 테스트에 파일 위치와 형식 확인 추가. 커밋 `78b92da`.
  - 확인: APK 에 `assets/function_words.csv` 포함, 앱 정상 실행 (크래시 0건).
- 단어 CSV 재가져오기: 저장 5000개, 건너뜀 0개.
- 오늘 목록 확인 (재실행 후): `get, people, go, make, think, time, know` 표시. 기능어 (be, the, and 등) 는 빠짐. 예문과 뜻 표시 확인.
- 오른쪽 TIP 칸 확인: `where (부사)` 표시.
- 설정 값 저장 확인: 파일에 `level_filter` 저장 (이전 확인).
