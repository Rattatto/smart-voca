## 3. 대안 시험 형식 (결정 필요)

예문이 없을 때 쓸 수 있는 방식입니다. 모두 현재 데이터(`word`, `meaning_ko`)로 만들 수 있습니다. 다만 charter BR-04 의 "일상 대화 문장 빈칸 채우기"와 다르므로 사용자 승인이 필요합니다.

| 방식 | 설명 | 장점 | 단점 |
|------|------|------|------|
| A. 뜻 보고 영단어 입력 | 한국어 뜻을 보여 주고 영단어를 직접 입력 | 구현이 단순함. FR-033 그대로 적용 | 문장 속 사용법을 익히지 못함 |
| B. 영단어 보고 뜻 고르기 | 영단어를 보여 주고 4지선다 중 뜻을 고름 | 보기는 같은 구간의 다른 단어에서 뽑으면 됨 | 객관식이라 찍기 가능성이 있음 |
| C. 뜻 보고 영단어 고르기 | B 를 반대로 함 | 영단어 기억을 확인할 수 있음 | 보기 생성이 B 와 같음 |

**결정 (261021): A 채택.** B, C 는 1차 범위에 넣지 않는다. 빈칸 문장 시험은 2차 버전으로 이관하며, 예문 확보 후 진행한다.

## 6. 사용자 결정 사항 (결과)

1. 시험 형식: **A 채택** (뜻 보고 영단어 입력)
2. 빈칸 시험(BR-04): **2차 버전으로 이관**
3. OI-12(품사), OI-13(예문): **보류.** 데이터가 생기거나 자체 생성이 가능해지면 사용자가 통보
4. 평점 열: **1차에 추가** (`rating`, 원문 그대로 저장). 세부 규칙은 추후 반영 (OI-14)
