# Smart Voca 데이터 설계서 (기말 과제, 서버 앱)

**파일 위치**: `ai-agent/claude/update/261125_데이터설계서.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: SQLite 테이블 정의와 제약, 스키마 버전 관리 방법을 정한다. 261021 데이터 설계서(Room)를 대체한다. 소스 코드는 포함하지 않는다.

---

## 1. 개요

- DB: SQLite 한 파일. 위치는 환경변수 `DB_PATH` (서버 `/data/voca.db`, 개발 PC `server/data/voca.db`)
- 생성: 앱이 시작할 때 `server/db.py` 의 `init_db()` 가 만든다 (VOCA-NFR-003)
- 버전 관리: `PRAGMA user_version`. 현재 **1**. 스키마를 바꿀 때는 버전을 올리고 `init_db()` 에 변환 단계를 추가한다
- 시각: `datetime('now', 'localtime')` 문자열 (`YYYY-MM-DD HH:MM:SS`)
- 외래 키: 연결마다 `PRAGMA foreign_keys = ON`

## 2. 테이블

### 2.1 `words` — 단어 (VOCA-FR-001~004)

| 열 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK, AUTOINCREMENT | 이력이 가리키는 식별자. 다시 가져와도 바뀌지 않는다 |
| word | TEXT | NOT NULL, UNIQUE, COLLATE NOCASE | 영단어. 대소문자 무시로 중복 금지 (요구사항 명세서 §4.3) |
| meaning | TEXT | NOT NULL | 뜻. 같은 철자의 뜻은 `; ` 로 합쳐 저장 |
| freq_rank | INTEGER | NULL 허용 | 빈도 순위. 목록 정렬에 쓴다 |
| level | TEXT | NULL 허용, `basic`/`intermediate`/`advanced` | 난이도 |
| pos | TEXT | NULL 허용 | 품사 (임시 동사는 `verb`) |
| example_en | TEXT | NULL 허용 | 영어 예문 |
| example_ko | TEXT | NULL 허용 | 예문 번역 |
| created_at | TEXT | NOT NULL | 등록 시각 |
| updated_at | TEXT | NOT NULL | 마지막 수정 시각 |

인덱스: `idx_words_freq_rank (freq_rank)`

## 3. 처리 규칙

| 처리 | 함수 (`server/word_repository.py`) | 규칙 |
|---|---|---|
| 직접 등록 | `add_word()` | 같은 철자가 있으면 `DuplicateWordError` |
| 수정 | `update_word()` | 다른 단어와 철자가 겹치면 `DuplicateWordError` |
| 삭제 | `delete_word()` | 이력은 CASCADE 로 함께 삭제 |
| 검색·목록 | `search_words()` | `word` 또는 `meaning` 부분 일치 (`LIKE`, `%`·`_` 이스케이프). 정렬 `freq_rank` 있는 것 먼저 → 순위 → 철자 |
| 일괄 등록 | `import_words()` | 기존 철자는 뜻 갱신, 선택 항목은 값이 있을 때만 갱신 |
| 첫 실행 적재 | `seed_starter_words()` | `starter_seeded` 가 없을 때만 1회 |

CSV 해석과 파일 안 중복 합치기는 `server/csv_import.py` 의 `parse_word_csv()` 가 맡는다 (요구사항 명세서 §4.2~4.3).
