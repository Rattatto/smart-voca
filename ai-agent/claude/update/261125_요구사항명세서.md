## 4. 단어 데이터와 중복 처리 방침 (VOCA-FR-003)

### 4.1 데이터 출처

| 데이터 | 넣는 방법 | 이유 |
|---|---|---|
| 임시 동사 120개 (`server/seed/starter_verbs.csv`) | 첫 실행 때 자동 적재 (1회) | 직접 작성한 데이터라 공개 리포에 둘 수 있다. 빈 화면으로 시작하지 않게 한다 |
| 5,000개 단어장 (`words_draft.csv`) | 설정 화면에서 업로드 | 출처 라이선스 미확인(RK-01). 리포·이미지에 넣지 않는다 |
| 과제 제공 CSV (`영단어,뜻`, 2,000개) | 설정 화면에서 업로드 | 요건 FR-003 확인용 |

### 4.2 CSV 형식

- 인코딩: UTF-8. 맨 앞 BOM 은 지우고 읽는다.
- 헤더 별칭 (공백 제거, 대소문자 무시)

| 항목 | 받는 헤더 | 필수 |
|---|---|---|
| 영단어 | `영단어`, `단어`, `word` | 예 |
| 뜻 | `뜻`, `의미`, `meaning`, `meaning_ko` | 예 |
| 빈도 순위 | `freq_rank` | 아니오 (정수가 아니면 비움) |
| 난이도 | `level` (`basic`, `intermediate`, `advanced`) | 아니오 (다른 값이면 비움) |
| 품사 | `pos` | 아니오 |
| 예문 | `example_en`, `example_ko` | 아니오 |

- 필수 열이 없으면 아무것도 저장하지 않고 빠진 열을 알려 준다.
- 영단어나 뜻이 비어 있거나, 영단어에 영문자·공백·`'`·`-`·`.` 이외 문자가 있으면 그 행을 건너뛰고 행 번호와 사유를 보여 준다.

### 4.3 중복 처리 (사용자 결정 261125, 방침 A)

1. **같은 단어의 기준**: 앞뒤 공백을 지운 철자가 대소문자 무시하고 같으면 같은 단어다.
2. **한 파일 안의 중복**: 하나로 합친다. 뜻은 나온 순서대로 `; ` 로 이어 붙이고, 똑같은 뜻은 한 번만 쓴다. 빈도 순위는 작은 값(더 자주 쓰는 쪽), 나머지 선택 항목은 처음 나온 값을 쓴다. 예: `like` → `좋아하다; ~처럼`
3. **이미 등록된 단어를 다시 가져올 때**: 뜻을 파일의 값으로 바꾼다. 선택 항목은 파일에 값이 있을 때만 바꾼다. 단어 id 는 유지되므로 암기·시험 이력이 이어진다.
4. **직접 입력(FR-001)으로 이미 있는 단어를 넣을 때**: 저장하지 않고 "이미 등록된 단어" 안내와 수정 링크를 보여 준다. 실수로 뜻을 덮어쓰지 않게 하려는 것이다.
5. 가져오기 결과로 새로 등록, 뜻 갱신, 파일 안에서 합친 수, 건너뛴 행을 보여 준다.
