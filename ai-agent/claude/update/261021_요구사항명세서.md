## 1. 개요

### 1.1 기준 문서
- 상위: `ai-agent/claude/update/261021_기획서.md` (BR-01~08, SC-01~04, §7 정책)

### 1.2 표기 규칙
- **ID:** `FR-xxx` (기능), `NFR-xxx` (비기능). 모든 항목은 BR 또는 SC 와 연결한다.
- **우선순위:** 필수(M), 권장(S), 선택(C). MoSCoW 기준.
- **인수 기준:** BDD 형식 (Given / When / Then). 테스트 정의서에서 시나리오로 그대로 쓴다.
- **상태:** 제안(P) 은 사용자 승인 전 값이다. 확정(C) 은 승인된 값이다. 보류 는 원본 데이터(품사 OI-12, 예문 OI-13)가 확보될 때까지 구현하거나 제작하지 않는 항목이다.

## 2. 용어

| 용어 | 정의 |
|------|------|
| 단어 항목 | CSV 한 행에 해당하는 단어 데이터 (`word`, `pos`, `meaning_ko`, `example_en`, `example_ko`, `freq_rank`, `level`) |
| 일일 단어 | 하루 동안 사용자에게 노출되는 단어 목록 |
| 재노출 후보 | 과거에 학습한 단어 중 재노출 간격이 지나 일일 단어에 다시 들어갈 수 있는 단어 |
| 시험 문제 | 예문에서 대상 단어를 빈칸으로 만든 문제 |
| 동사 비중 | 일일 단어 또는 시험 문제 중 `pos = verb` 항목이 차지하는 비율 |

## 3. 기능 요구사항 (FR)

### 3.1 데이터 관리

| ID | 요구사항 | 우선순위 | 추적 | 상태 |
|----|----------|---------|------|------|
| FR-001 | 앱은 CSV 파일을 읽어 단어 항목을 로컬 DB에 적재한다. | M | BR-07 | C |
| FR-002 | CSV 필수 열(`word, meaning_ko, freq_rank, level`)이 없으면 적재를 중단하고 누락된 열 이름을 알려 준다. 선택 열(`pos, example_en, example_ko, rating`)은 열이 없어도 적재하며, 값이 비어 있어도 허용한다. | M | BR-07 | C |
| FR-003 | 형식이 잘못된 행(빈 값, 숫자 아님 등)은 건너뛰고, 건너뛴 행 번호와 사유를 보여 준다. | M | BR-07 | P |
| FR-004 | `word` 와 `pos` 조합이 같은 행은 중복으로 보고 한 번만 저장한다. | M | BR-07 | 보류 (OI-12) |
| FR-005 | 적재된 단어 수가 2,000개 이상 가능해야 한다. 상한은 두지 않는다. | M | BR-07 | P |

**인수 기준 (FR-001, FR-003):**
- **Given** 필수 열을 모두 가진 CSV 파일 (2행 중 1행이 `freq_rank` 가 빈 값)
- **When** 사용자가 CSV 가져오기를 실행
- **Then** 유효한 1행만 저장되고, 건너뛴 행 번호 2와 사유 "freq_rank 누락"이 화면에 표시된다.

### 3.2 일일 단어

| ID | 요구사항 | 우선순위 | 추적 | 상태 |
|----|----------|---------|------|------|
| FR-010 | 앱은 설정된 개수만큼 일일 단어 목록을 만든다. | M | BR-02, SC-01 | C |
| FR-011 | 일일 단어는 설정된 난이도 범위의 단어에서 고른다. | M | BR-05 | C |
| FR-012 | 일일 단어에서 동사 비중이 설정값(기본 60%)에 가깝도록 고른다. 적용 가능한 동사가 부족하면 가능한 만큼만 채우고 나머지는 다른 품사로 채운다. | M | BR-01 | 보류 (OI-12) |
| FR-013 | 같은 날에는 목록을 바꾸지 않는다. 날짜가 바뀌면 새 목록을 만든다. 날짜 기준은 기기의 로컬 시간이다. | M | BR-02 | P |
| FR-014 | 재노출 후보가 있으면 일일 단어에 우선 포함한다. 포함 개수는 설정 개수 안에서 정하며, 재노출 단어는 일일 단어의 최대 30%를 넘지 않는다. | M | BR-03 | C |
| FR-015 | 일일 단어 목록에서 각 단어의 노출 시각을 기록한다. | S | BR-02 | P |

**인수 기준 (FR-012):**
- **Given** 설정 개수 10개, 동사 비중 60%, 동사 단어 100개 이상 적재
- **When** 일일 단어 목록을 생성
- **Then** 목록 10개 중 동사가 6개이다.

**인수 기준 (FR-013):**
- **Given** 오늘 날짜로 생성된 일일 단어 목록
- **When** 같은 날 앱을 다시 실행
- **Then** 목록의 단어와 순서가 동일하다.

### 3.3 재노출

| ID | 요구사항 | 우선순위 | 추적 | 상태 |
|----|----------|---------|------|------|
| FR-020 | 단어를 학습(일일 단어로 노출 후 학습 완료 처리)하면 재노출 예정일을 기록한다. | M | BR-03 | P |
| FR-021 | 재노출 간격은 학습 후 1, 3, 7, 14, 30일로 한다. 간격이 지나면 재노출 후보가 된다. | M | BR-03 | C |
| FR-022 | 시험 결과(정답, 오답)와 관계없이 재노출 규칙을 똑같이 적용한다. | M | BR-03 | C |
| FR-023 | 재노출 간격을 모두 지난 단어는 재노출 후보에서 제외한다 (30일 이후 다음 주기 없음). | S | BR-03 | C |

**인수 기준 (FR-021, FR-022):**
- **Given** 단어 A 를 시험에서 오답으로 학습 완료한 날이 2026-11-01
- **When** 2026-11-04 에 일일 단어를 생성
- **Then** 단어 A 는 재노출 후보에 포함되고, 간격 3일 단계가 적용된다.

> 재노출 간격 30일 이후를 어떻게 할지는 OI-04 에서 함께 확정한다.

**인수 기준 (FR-033):**

## 5. 데이터 요구사항

### 5.1 CSV 형식 (제안)
| 열 | 타입 | 필수 | 설명 | 예 |
|----|------|------|------|----|
| `word` | 문자열 | Y | 영어 단어 원형 | `go` |
| `pos` | 문자열 | N | 품사 (`verb`, `noun`, `adj`, `adv` 등). OI-12 확보 전까지 비움 | `verb` |
| `meaning_ko` | 문자열 | Y | 한국어 뜻 | `가다` |
| `example_en` | 문자열 | N | 일상 대화 예문. 대상 단어 포함. OI-13 확보 전까지 비움 | `She went to school.` |
| `example_ko` | 문자열 | N | 예문 해석 | `그녀는 학교에 갔다.` |
| `freq_rank` | 정수 | Y | 빈도 순위 (작을수록 자주 쓰임) | `12` |
| `level` | 문자열 | Y | 난이도 (`basic`, `intermediate`, `advanced`) | `basic` |
| `rating` | 문자열 | N | 원본 별점 표기 그대로 (`★★★★`, `☆`, `△` 등). 의미는 미확정 | `★★★★` |

- 인코딩: UTF-8 (BOM 허용).
- 예문에 대상 단어가 없으면 그 행은 시험에서 제외한다 (FR-003 과 같이 건너뛰고 사유 표시, 제안).

### 5.2 난이도 매핑
| 설정 값 | CSV `level` 값 |
|--------|----------------|
| 기초 | `basic` |
| 중급 | `intermediate` |
| 심화 | `advanced` |
| 전체 | 모든 값 |

빈도 순위 구간 (확정 261021): 1~1000 `basic`, 1001~3000 `intermediate`, 3001~5000 `advanced`.
