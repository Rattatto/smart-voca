## 2. 배경 및 목적

### 2.1 배경
영어로 일상 대화를 하려면 많은 단어를 외우기보다 자주 쓰는 핵심 단어를 꾸준히 익히는 것이 효과적이라고 본다. 특히 일상 대화에서 자주 쓰이는 **동사**가 문장을 만드는 핵심이다. 이 앱은 이 점에 착안한다.

### 2.2 목적
- 영어 일상 대화에 필요한 **동사 위주 단어**를 매일 반복 노출하여 익히게 한다.
- 핵심 모토: **"동사만 알아도 대박이다"**
- 단어 시험을 통해 뜻에 맞는 영단어를 떠올릴 수 있는지 확인한다.

### 2.3 성공 기준
| ID | 기준 | 측정 방법 |
|----|------|----------|
| SC-01 | 일일 단어 목록이 매일 설정한 개수만큼 제공된다 | 설정값과 실제 노출 개수 비교 |
| SC-02 | 시험 문제가 한국어 뜻을 보여 주고 영단어를 입력받는 방식으로 출제된다 | 출제 샘플 검토 |
| SC-03 | 시험 결과와 무관하게 지난 단어가 재노출된다 | 재노출 규칙 테스트 |
| SC-04 | 앱을 종료해도 단어 목록과 시험 이력이 유지된다 | 재실행 후 데이터 확인 |

## 4. 시스템 범위 (System Scope)

### 4.1 포함 범위 (In Scope, 1차)
1. **일일 단어 노출:** 환경설정의 개수와 난이도에 맞춰 매일 단어 목록을 보여 준다.
2. **단어 데이터 로드:** 영단어, 한국어 뜻, 빈도 순위, 난이도, 별점을 담은 CSV 파일을 읽어 기기 DB에 적재한다. 품사와 예문은 확보되면 같은 파일에 추가한다.
3. **단어 시험:** 한국어 뜻을 보고 영단어를 입력하는 문제를 출제하고 채점한다.
4. **재노출 관리:** 지나간 단어를 정해진 간격 뒤에 다시 일일 단어 후보에 넣는다.
5. **환경설정:** 일일 노출 개수, 난이도, 시험 문제 수를 조절한다. 동사 비중은 저장만 하며 품사 확보 후 적용한다.
6. **이력 저장:** 단어 목록, 학습 기록, 시험 이력을 기기 내부에 영구 저장한다.

### 4.2 제외 범위 (Out of Scope, 1차 버전)
- 서버, 계정 로그인, 다중 기기 동기화
- 단어장 공유 및 다른 사용자와의 협업
- 음성 인식 또는 발음 평가
- AI 예문 생성 및 기기 내장 LLM(Gemini Nano) 기반 기능 (2차 버전에서 검토, 261021 보류 결정)
- 일상 대화 문장 빈칸 채우기 시험 (2차 버전, 예문 확보 후 진행, 261021 결정)
- 학습 통계 화면 (2차 버전, 261021 결정)
- 웹 및 iOS 버전

### 4.3 주요 구성 요소 (설계 초안 기준)
| 구분 | 명칭 | 역할 |
|------|------|------|
| 데이터 적재 | `CsvWordLoader` | CSV 파싱, 검증, 적재 요청 |
| 저장소 | `WordRepository`, `StudyRepository`, `ExamRepository`, `SettingsStore` | 저장소 접근 캡슐화 |
| 일일 선정 | `DailyWordSelector`, `ReviewScheduler` | 개수, 난이도, 재노출 규칙으로 일일 목록과 일정 관리 |
| 시험 | `ExamGenerator`, `ExamGrader` | 뜻 보기 문제 출제와 채점 |

상세 구조는 `261021_아키텍처설계서.md` 에 정의되어 있다.

## 6. 가정, 제약, 리스크

### 6.1 가정
- 사용자는 안드로이드 기기를 가지고 있으며 인터넷 연결 없이 사용한다.
- 단어 데이터는 CSV 파일로 준비할 수 있다.

### 6.2 제약
- 개발자 1인이 수업 과제로 진행한다. 수업은 주 1회이며, 목표 완료일까지 수업은 약 4~5회다.
- 서버를 두지 않으므로 데이터 백업과 복구는 기기 내에서만 가능하다.
- 학습 기록은 기기 밖으로 나가지 않는다.
- 단어 데이터는 라이선스가 확인되기 전까지 앱에 번들하지 않는다. 사용자가 CSV 를 가져오는 방식으로만 들어온다 (261021 방침).

### 6.3 리스크
| ID | 리스크 | 영향 | 대응 |
|----|--------|------|------|
| RK-01 | 단어 데이터의 출처나 라이선스 문제 | 배포 불가 | 앱에 번들하지 않음. CSV 가져오기 방식으로 제한 |
| RK-02 | 예문 미확보 | 빈칸 시험 불가 | 1차는 뜻 보고 영단어 입력 방식으로 대체. 빈칸 시험은 2차 |
| RK-03 | 재노출 규칙이 복잡해져 일정 관리가 어려움 | 일일 목록 오류 | 간격을 고정된 목록으로 두고 테스트 케이스 작성 |
| RK-04 | 앱 삭제 시 학습 데이터 소실 | 이력 손실 | 백업 기능은 2차 버전에서 검토 |
| RK-05 | 품사 미확보 | 동사 우선 기능 미적용 | 설정 값만 저장, 품사 확보 시 적용 |
| RK-06 | 주 1회 수업 일정으로 개발 기간이 짧음 | 일정 지연 | 주차별 마일스톤 점검 (작업 계획서 §4) |

## 7. 난이도와 데이터 정책

- **난이도 (확정):** 빈도 순위 기준. 1~1000 기초 (`basic`), 1001~3000 중급 (`intermediate`), 3001~5000 심화 (`advanced`).
- **재노출 간격 (확정):** 학습 후 1, 3, 7, 14, 30일 뒤에 다시 일일 단어 후보에 넣는다. 30일 이후에는 재노출하지 않는다.
- **품사 범위 (확정):** 전체 품사를 대상으로 한다.
- **동사 비중 (확정 값):** 기본 60%, 설정 범위 30~90% (10 단위). 품사 확보 전까지 적용하지 않는다.
- **일일 개수 (확정 값):** 기본 10개, 설정 범위 5~30개. 재노출 단어는 일일 목록의 최대 30%.
- **시험 문제 수 (확정 값):** 기본 10문제, 설정 범위 5~20문제.
- **CSV 열 구성:** 필수 `word, meaning_ko, freq_rank, level`. 선택 `pos, example_en, example_ko, rating` (값을 비워 둘 수 있음).
- **별점 (`rating`):** 원본 표기를 그대로 저장한다. 기호의 의미는 세부 규칙 확정 시 반영한다 (OI-14).
- **데이터 규모:** 최소 2,000개 이상. 추가 가능하도록 설계한다.
- **현재 데이터:** "필수 영어단어 Top 5,000" PDF 5종에서 5000개 추출 (순위, 영단어, 뜻, 별점). 품사와 예문은 없다. 출처는 개인 블로그로 기재되어 있으며 라이선스는 확인되지 않았다.
