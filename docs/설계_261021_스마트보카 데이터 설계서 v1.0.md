## 2. 테이블 정의

### 2.1 `word` (단어)

| 열 | 타입 | 필수 | 제약 | 설명 |
|----|------|------|------|------|
| `id` | 정수 | Y | PK, 자동 증가 | 내부 식별자 |
| `word` | 문자열 | Y | | 영단어 원형 |
| `pos` | 문자열 | N | | 품사. OI-12 확보 전까지 빈 값 |
| `meaning_ko` | 문자열 | Y | | 한국어 뜻 |
| `example_en` | 문자열 | N | | 예문. OI-13 확보 전까지 빈 값 |
| `example_ko` | 문자열 | N | | 예문 해석 |
| `freq_rank` | 정수 | Y | UNIQUE | 빈도 순위. 1차 기준 중복 키 |
| `level` | 문자열 | Y | `basic`, `intermediate`, `advanced` | 빈도 구간으로 정한 난이도 (OI-11) |
| `rating` | 문자열 | N | | 원본 별점 표기 원문 (OI-14) |

- 인덱스: `freq_rank`(UNIQUE), `level`
- 중복 키: 1차는 `freq_rank` 기준. 품사 확보 후 `word` + `pos` 기준으로 바꾼다 (FR-004 보류 해제 시)
- 같은 철자의 다른 품사는 별도 행으로 저장한다 (원본의 중복 18건)

### 2.2 `daily_list` (일일 목록)

| 열 | 타입 | 필수 | 제약 | 설명 |
|----|------|------|------|------|
| `date` | 문자열 (YYYY-MM-DD) | Y | PK 일부 | 기기 로컬 날짜 |
| `word_id` | 정수 | Y | PK 일부, FK → `word.id` | 단어 |
| `position` | 정수 | Y | | 목록 내 순서 (1부터) |
| `source` | 문자열 | Y | `new`, `review` | 신규 단어인지 재노출인지 |
| `daily_count` | 정수 | Y | | 생성 시점의 일일 개수 설정 스냅샷 |
| `level_filter` | 문자열 | Y | `basic`, `intermediate`, `advanced`, `all` | 생성 시점의 난이도 스냅샷 |
| `shown_at` | 문자열 (ISO 8601) | Y | | 노출 시각. 목록을 처음 만든 시각과 같다 (FR-015) |

- 기본키: (`date`, `word_id`). `word_id` 에 인덱스
- 같은 날짜의 목록은 한 번 만들면 바뀌지 않는다 (FR-013)
- 설정 스냅샷으로 FR-045 (설정 변경 반영 시점)를 구현한다
- 구현 현황 (2026-11-11, #2): `source` 는 `new` 만 쓴다. `review` 는 #3 에서 추가한다. DB 버전 2 에서 `MIGRATION_1_2` 로 테이블을 만든다

### 2.3 `study_record` (학습 기록)

| 열 | 타입 | 필수 | 제약 | 설명 |
|----|------|------|------|------|
| `id` | 정수 | Y | PK, 자동 증가 | |
| `word_id` | 정수 | Y | FK → `word.id` | |
| `studied_at` | 문자열 (ISO 8601) | Y | | 학습 완료 시각 |
| `study_date` | 문자열 (YYYY-MM-DD) | Y | | 학습 완료 날짜 (로컬) |

- 한 단어를 여러 번 학습할 수 있다. 재노출로 다시 학습하면 행이 추가된다.
- 신규 여부 판단: `word_id` 가 이 테이블에 없으면 신규 단어

### 2.4 `review_schedule` (재노출 일정)

| 열 | 타입 | 필수 | 제약 | 설명 |
|----|------|------|------|------|
| `word_id` | 정수 | Y | PK, FK → `word.id` | |
| `step` | 정수 | Y | 0~5 | 재노출 단계. 0 = 첫 학습 후 대기 |
| `next_review_date` | 문자열 (YYYY-MM-DD) | N | | 다음 재노출 날짜. 종료 시 빈 값 |
| `updated_at` | 문자열 (ISO 8601) | Y | | 마지막 갱신 시각 |

- 간격: step 0 → 1일, 1 → 3일, 2 → 7일, 3 → 14일, 4 → 30일 (FR-021)
- step 5 이상은 재노출 종료 (FR-023). `next_review_date` 는 빈 값

### 2.5 `exam_attempt` (시험 이력)

| 열 | 타입 | 필수 | 제약 | 설명 |
|----|------|------|------|------|
| `id` | 정수 | Y | PK, 자동 증가 | |
| `word_id` | 정수 | Y | FK → `word.id` | |
| `attempt_date` | 문자열 (YYYY-MM-DD) | Y | | 시험 날짜 (기기 로컬, FR-036) |
| `attempted_at` | 문자열 (ISO 8601) | Y | | 답 제출 시각 |
| `shown_meaning` | 문자열 | Y | | 문제로 보여 준 뜻 (스냅샷) |
| `user_input` | 문자열 | Y | | 사용자가 입력한 값 (원문) |
| `is_correct` | 정수 (0/1) | Y | | 채점 결과 |

- 시험 이력은 재노출 일정(`review_schedule`)을 바꾸지 않는다 (FR-037)

## 3. 설정 (DataStore)

| 키 | 타입 | 기본값 | 범위 | 요구사항 |
|----|------|--------|------|---------|
| `daily_count` | 정수 | 10 | 5~30 | FR-040 |
| `level_filter` | 문자열 | `all` | `basic`, `intermediate`, `advanced`, `all` | FR-041 |
| `verb_ratio` | 정수 (%) | 60 | 30~90, 10 단위 | FR-042 (품사 확보 전까지 저장만) |
| `exam_size` | 정수 | 10 | 5~20 | FR-043 |

## 4. CSV 가져오기 규칙

| 항목 | 규칙 |
|------|------|
| 인코딩 | UTF-8 (BOM 허용) |
| 필수 열 | `word`, `meaning_ko`, `freq_rank`, `level` |
| 선택 열 | `pos`, `example_en`, `example_ko`, `rating` (없으면 빈 값) |
| 필수 값 검증 | `word` 영문자, `meaning_ko` 비어 있지 않음, `freq_rank` 양의 정수, `level` 허용 값 |
| 재가져오기 | 같은 `freq_rank` 는 내용을 갱신한다. 학습 기록은 유지 |
| 실패 처리 | 실패 행은 건너뛰고 번호와 사유를 보고 (FR-003) |

---

## 5. 데이터 무결성

- 학습 기록, 재노출 일정, 시험 이력은 `word_id` 로 연결된다. 단어를 지울 때는 연결된 기록도 함께 처리한다 (삭제 정책은 구현 단계에서 확정)
- 날짜는 모두 기기 로컬 날짜 기준이다. 자정 이후 첫 실행에서 새 목록을 만든다 (FR-013)
